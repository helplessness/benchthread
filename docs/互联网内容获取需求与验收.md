# TCode 互联网内容获取：交付范围与验收

不新增浏览器后端。通用搜索与公开网页读取复用 websearch / webfetch；动态页面及人工登录复用现有 browser 和桌面接管；论文检索与 PDF 下载维持现有专用 MCP 路由。外部浏览器、电脑控制和日常 Chrome 登录态不参与自动回退。

## 公开能力边界

下文列出已接入的读取动作，不代表所有站点和动作都通过真实桌面验收。渠道管理支持启停、公开连接检查，以及适用渠道的隔离登录与退出；不绕过站点风控。

指定来源时不静默更换站点。结果区分原生字幕和转写、正文和摘要、完整结果和部分结果。

## 登录确认

明确登录阻塞后暂停相关任务，前端展示站点与受阻步骤，提供「接管并登录」「稍后处理」「取消本次读取」。已能读取目标内容则不重复询问。用户在隔离浏览器内本人登录，接管后收起观察窗，不向模型发送登录表单、凭据及画面。刷新、断线和切换面板不是交还。

主动交还后在同一会话验证原动作确能访问目标内容，再续跑一次；不重放历史点击，不重跑整轮，不切回无登录态的搜索工具。验证不通过保持等待或明确返回不可验证，不能报成功。会话丢失提示重新打开；取消后拒绝迟到的交还。无交互入口时提示使用支持接管的桌面端，不无限等待。

## 验收与当前边界

桌面结构化渠道读取自带登录等待。普通浏览器导航的通用登录提示仍由 `TCODE_DESKTOP_BROWSER_LOGIN_PREVIEW=1` 启用。

登录墙、验证码、站点拒绝或 DNS 拦截都不算读取成功。单元测试不等同于真实桌面验收，具体状态见下文。

### Agent Reach 受控接入

开发桌面可由运维设置 `TCODE_AGENT_REACH_PYTHON` 启用内置 `internet_content`，不启动额外 MCP 进程或浏览器。该工具的 `channels` 动作读取已准入动作；`TCODE_AGENT_REACH_CHANNELS` 可限制可用渠道。在「设置 → 互联网渠道」可启停已准入渠道并检查公开读取样例。支持浏览器读取的渠道可从这页打开隔离登录窗口，或明确退出当前工作区的本地登录；不会使用或修改系统浏览器。浏览器登录态在内存中，不随进程重启持久化。关闭启用开关本身不会清除登录态。

依赖固定为 `c70ae6da5d39bc90e09ad2ae0575ccc89f31e284`（1.6.1），不 fork，不执行上游 setup、登录、浏览器命令，不安装全局 Skill。用独立 Python 环境安装该 Git revision，将其解释器绝对路径传给 `TCODE_AGENT_REACH_PYTHON`。MCP 服务入口为 `python -m tcode_agent.server.agent_reach_mcp`（stdio，由支持该传输的部署显式注册；不默认注入桌面运行时）。

- GitHub：仓库搜索、仓库/README、issue/PR 与评论读取（公开 GitHub API）。
- V2EX：热门、节点、帖子与回复、用户（公开 V2EX API）。
- B 站：公开 API 支持热门和视频信息；原桌面浏览器支持搜索和第一分 P 的平台字幕读取。字幕按需核对同一会话登录态，不导出 Cookie，也不把缺内容报成「没有字幕」。
- YouTube：公开搜索、视频信息、字幕；雪球股票搜索与行情来自腾讯公开行情端点，热帖、热股另走原桌面浏览器的雪球会话。
- YouTube 和小宇宙：明确请求音频转写时走 Groq Whisper，不以字幕代替转写。由本人在 [Groq 控制台](https://console.groq.com/keys) 创建 Key，在本机私有 `.tcode-local/desktop.env` 添加 `TCODE_GROQ_API_KEY=...`，确保 PATH 中有 `ffmpeg` 和 `ffprobe` 后重启桌面端。不要在聊天、命令行参数或 Git 中传递 Key。公开音频会发送给 Groq，可能计费；尚未完成真实转写验收。
- 小红书、Reddit、BOSS、LinkedIn、X、Facebook、Instagram：在原桌面浏览器内执行预设只读操作，同站点、同目标且内容选择器命中才返回。X、Facebook、Instagram 默认关闭。没有实站证据的动作不能算验收通过。

运行可重复的公开联网样例：在项目根目录指定独立环境的解释器绝对路径并设置 `TCODE_AGENT_REACH_LIVE_TEST=1`，执行 `python -m pytest -q scripts/tests/test_agent_reach_mcp.py`。这些检查不能替代逐渠道与真实桌面的最终验收。

断线或界面重载时按工作区和父会话找回仍在等待的登录提示。后端重启时，对**停在登录等待的结构化只读动作**提供「恢复原读取」：重新打开该动作、需要时重新登录，验证取得内容后用已有续跑机制把结果交回原会话，不重放点击、输入或提交。普通导航及其他在途步骤不冒充已恢复。真实断线和后端重启验收尚未完成。

桌面预览新增由调用者指定的目标元素和文字验证：相同会话重新访问原址、HTTP 成功且可见目标内容匹配才返回验证结果。固定 HTTPS 响应的真实 Electron 回归脚本 `desktop/scripts/browser-login-e2e.cjs` 同时检查 HTTP 200 拒绝页和正确内容；这不是第三方账号实测。

### 已验证与待验收

- 桌面实站抽测中，GitHub、V2EX、B 站、YouTube 和雪球的部分公开读取返回了非空结果；V2EX 的启停和检查状态在界面重载后保留。
- 固定响应的 Electron 回归验证了显式交还、原目标回读、拒绝页拦截和会话隔离。它不能代表真实账号的登录、退出或重启恢复通过。
- 全渠道逐动作、真实转写、真实账号登录与退出、断线及后端重启恢复仍待完整验收。
