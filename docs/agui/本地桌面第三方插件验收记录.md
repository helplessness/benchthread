# 本地桌面第三方插件验收记录

2026-11-22 在 macOS 源码运行的 TCode Electron 独立测试实例完成验收。使用工作区配置的 DeepSeek Flash 处理随包提供的两页测试 PDF。文献团队的阅读员和复核协调者均实际调用模型。本轮验收不依赖远程 MCP。

## 桌面观察结果

| 操作 | 实际结果 |
|---|---|
| 从本地上传 ZIP，确认加载 | 全新工作区自动解包并登记。用户同意文档、团队和分享权限后，扩展二级侧栏出现“文献证据助手”，模式选择器出现协调者。 |
| 选择 PDF 并要求两条证据 | 第 1 页返回 A 组完成 18/20、B 组完成 12/20 的原文；第 2 页返回未随机分组、未测量长期结局的原文。 |
| 分别核对两张卡，再刷新桌面窗口 | 两次复核分别绑定原条目，刷新后仍能查看结果。 |
| 选中第 2 页并带入对话 | 草稿包含第 2 页的引文和条目标识。原 PDF 附在草稿中，打开工作区文件核对，其字节与输入一致。随后从主聊天发出追问，得到第 2 页及非随机分组限制因果解释的回答。 |
| 在第三次复核运行中切到 OpenCode | 弹窗显示当前运行数。外部 harness 中面板与插件 Agent 入口消失，读取原面板地址返回 409。切回 TCode 后可查看第三次复核的结果。 |
| 撤销文档读取，再次选 PDF 提交 | 后端拒绝新读取，面板显示授权提示。 |
| 点击卸载，再确认删除插件 | 侧栏入口消失，安装目录和登记已清除。原工作区仍有 4 份已完成运行的结果摘要和已分享的 PDF。 |
| 从工作区开发目录加载 | 分别用只含 HTML 的插件和只含角色定义的插件验证。两者分别通过面板与 Agent 选择器访问，停用后保留开发源码。 |
| 停止一项新提交的面板任务 | 点击“停止任务”后，面板显示任务已停止。 |

最终 ZIP 验收工作区名为 `panel-test-1795282769715507000`，首次查询的运行 ID 为 `053dd963-7ca2-4ad9-b53c-7621ed2bf16f`。其余三次为用户点击发起的单条复核。运行记录和产物均在独立测试实例中。
